# SuperOfc 1.0 release notes (draft)

SuperOfc 1.0 is the first complete version: employees, attendance from ZKTeco terminals, leave, payroll, loans, income tax and reports, on one Windows PC.

## What is in 1.0
- **Employees:** profiles, job history, documents with expiry dates, and import from Excel or CSV with a check of every row before anything is saved.
- **Attendance and leave:** shifts, a colour-coded monthly sheet, corrections with reasons, and leave types with balances and approval.
- **Devices:** ZKTeco fingerprint and face terminals on the network, automatic sync, device users, fingerprint backup, and import from USB or a file.
- **Payroll:** salary components with formulas, structures, salary revisions, a monthly run with review, finalize and void, payslip PDFs, and bank and cash sheets.
- **Loans and advances:** requests with a live schedule, approval against the minimum net pay, automatic deductions, settlement and write-off.
- **Income tax:** rules per fiscal year with versions, employee declarations, a yearly projection with year-end true-up, statements and a summary.
- **Reports:** seven core reports with preview, PDF and Excel. The dashboard shows each module at a glance.
- **Safety:** daily and pre-update backups, restore, an audit log of every change, roles, lock screen, and full data export.

## Before you rely on it
- **Tax:** only a sample tax pack ships. Enter your country's rules on the Tax page, or wait for the country pack.
- **Language:** English. A Bengali translation has started but is not offered yet.

## Upgrading from a beta
Install over the beta. SuperOfc backs up the data file before upgrading it. If anything goes wrong, reinstall the beta and restore the backup marked "before update".

## Known limits
- One PC per office; sharing the data file over the network is not supported.
- Payroll is monthly only and is computed after the month ends.
