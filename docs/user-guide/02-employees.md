# Employees

## Adding an employee
On **Employees**, select **New employee** (Ctrl+N). Code, full name and join date are required; everything else can be added later. Bank and tax details are only visible to roles that see salaries.

## Importing from Excel or CSV
Use this to bring in your existing staff list in one go.

1. On **Employees**, select **Import**.
2. Select **Download template**. It is an Excel file with the right column headings and one example row.
3. Fill in one row per employee. Required columns are **Code**, **Full name** and **Join date**. Optional columns: gender, date of birth, phone, e-mail, address, national ID, confirmed, department, designation, location, grade, payment mode, bank name, bank branch, bank account, tax ID and overtime eligible. Your own CSV file also works if its column headings match the template; capital letters do not matter.
4. Select **Choose file**. SuperOfc checks every row and lists any problems by row number, for example a code that already exists or a date it cannot read. Dates can be written as 2025-07-01, 01/07/2025 or 1 Jul 2025.
5. If a department, designation, location or grade does not exist yet, tick **Create departments, designations, locations and grades that do not exist yet** and they are added for you.
6. When there are no problems, select **Import N employees**. If there are problems, **Save problem list** gives you the list to fix; save the file and select **Check again**.
   All rows are saved together. If anything fails, nothing is saved, so you can fix the file and try again.

To export, use **Export** on the Employees page. It saves the list you are looking at, with the same filters, to Excel or CSV.

## The employee page
Each employee has tabs for the profile, **Job history** (confirm, promote, transfer, mark as left, rejoin) and **Documents** with expiry dates. Depending on your role there are also **Salary**, **Attendance**, **Leave**, **Loans** and **Tax** tabs.

Marking someone as left asks for the last working day and a reason. Their final month's payroll recovers any loan balance.
