# Loans and advances

1. On **Loans**, select **New loan**. Choose the employee, loan or salary advance, amount, interest if any, number of installments and the first month. The form shows the schedule and the employee's net pay after the installment.
2. Accounts or Admin **approve** or **reject** it. Approval is refused if net pay would fall below the minimum set in the payroll rules.
3. Select **Pay out** when the money is given.

Installments are taken from salary automatically. If an installment would push net pay below the minimum, it moves to the end of the loan.

Cash repayments, early settlement and write-off are on the loan page. Early settlement charges interest according to your loan rules.

When an employee leaves, the remaining balance is recovered from the final salary as far as the minimum net pay allows. Anything left is shown as owed.

Each loan has a statement with a running balance that you can save as PDF.
