# SuperOfc user guide

SuperOfc runs your office's people work on one Windows PC: employees, attendance from fingerprint and face terminals, leave, salaries, loans, income tax and reports. Your data stays on this PC and is backed up every day.

Read these in order the first time:

1. [Getting started](01-getting-started.md): first run, signing in, users and roles.
2. [Employees](02-employees.md): adding people, importing from Excel or CSV, documents and history.
3. [Attendance and leave](03-attendance-and-leave.md): shifts, the monthly sheet, corrections, leave requests.
4. [Devices](04-devices.md): connecting ZKTeco terminals and fixing unknown punches.
5. [Payroll](05-payroll.md): salary components, salaries, the monthly payroll and payslips.
6. [Loans and advances](06-loans.md): requests, approval, deductions and settlement.
7. [Income tax](07-tax.md): tax rules, employee declarations and statements.
8. [Reports and dashboard](08-reports.md): every report and what the dashboard tiles mean.
9. [Settings, backups and help](09-settings-and-backup.md): policies, backups, restore, updates, diagnostics.

Keyboard: Ctrl+N creates a new item on list pages, F5 refreshes, Ctrl+L locks the screen.
