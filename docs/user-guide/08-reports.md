# Reports and dashboard

## Reports
On **Reports**, pick a report on the left, set the month, period, department or other choices, and select **Show report**. Save it with **PDF** or **Excel**.

| Report | Shows |
|--------|-------|
| Attendance summary | Days present, late, half day, absent, on leave, holidays, weekly off and overtime hours for a month, per employee or per department. |
| Late and absent list | Each late arrival and absence in a period, with the first punch and minutes late. |
| Overtime | Overtime hours per employee for a month, and the overtime paid once payroll is finalized. |
| Headcount, joiners and leavers | Employees at the start and end of a period, joiners and leavers, per department, with turnover. |
| Salary cost by department | Gross, deductions, net pay and employer contributions from finalized payroll. |
| Loan ledger | Every loan pay-out and repayment in a period. |
| Leave balances | Opening, credited, taken, adjusted and remaining leave per employee and leave type. |

Salary, loan and tax reports appear only for roles that can see salaries. Attendance for the current month counts days up to today.

## Dashboard
The dashboard shows headcount, today's attendance, leave waiting for approval, last month's payroll, loans outstanding, devices that need attention, documents that expire within 30 days and the last backup. Select a tile to open its page.
