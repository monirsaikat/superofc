# Settings, backups and help

## Backups
SuperOfc backs up your data every day and before every update, and keeps recent copies. Under **Settings › Backup** you can **Back up now**, change how many are kept, and **Restore** one. Restoring replaces the current data with the backup; a copy of the current data is made first.

Copy backups to a USB drive or another PC from time to time. A backup on the same disk does not protect against a broken disk.

## Updates
Updates download in the background and install when you restart. Choose the channel and whether to install automatically under **Settings › Updates**.

## Export all data
**Settings › About › Export all data** saves every table to a folder: one Excel workbook per area and one JSON file. Passwords, device keys and fingerprint templates are not included. Use it to keep your own records or to move to another system.

## When something goes wrong
- **Settings › About › Export diagnostics** saves a zip with recent logs and version details for support. It contains no salaries or passwords.
- If SuperOfc finds the data file damaged when it starts, it stops before changing anything and offers to restore a backup or open the data folder.
