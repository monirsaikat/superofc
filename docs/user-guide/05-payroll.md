# Payroll

## Set up once
1. **Salary components** (Settings): earnings and deductions such as basic, house rent, medical or provident fund. A component is a fixed amount, a percentage of basic or gross, or a formula such as `BASIC * 0.1`. Mark which earnings are taxable.
2. **Salary structures** (Settings): ready-made sets of components, for example "Officer" or "Worker".
3. **Payroll rules** (Settings › Policies): pay per day basis, overtime rates, rounding and the minimum net pay.

## Salaries
On an employee's **Salary** tab, select **New salary**, pick a structure or enter components, and choose the date it starts. A live preview shows the monthly gross and net. To give many people a raise at once, use **Salary revision** on the Payroll page.

## Running a month
Payroll is run after the month ends.

1. On **Payroll**, select the month and **Compute**. Attendance is worked out again first.
2. Review the payslips. Warnings show missing punches, missing salaries or skipped loan installments. Add one-off bonuses or deductions where needed and compute again.
3. Select **Finalize payroll**. The month is locked, and loan and tax deductions are recorded.
4. Save **Payslips PDF** (one file for everyone or one file per employee), the bank transfer sheet, the cash sheet and the payroll register.
5. Mark payslips **paid** one by one or all at once.

If a finalized month is wrong, **Void** the run with a reason. This works only for the latest month, and only while no payslip is marked paid. The month opens again; the voided payslips stay on record.
